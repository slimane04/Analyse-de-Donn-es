# Analyse de Données

Ce dépôt contient plusieurs notebooks d'analyse de données et de machine learning, ainsi que deux jeux de données associés.

## Structure du dépôt

- `K-clustering.ipynb` : Analyse et visualisation de clustering avec K-means ou méthodes similaires.
- `KNN.ipynb` : Implémentation et étude du classifieur K-Nearest Neighbors.
- `MDS.ipynb` : Analyse en composantes principales et réduction de dimensions avec Multi-Dimensional Scaling.
- `NMF.ipynb` : Décomposition en matrices non négatives (Non-negative Matrix Factorization).
- `Overfitting et Validation.ipynb` : Étude du surapprentissage et des méthodes de validation pour évaluer les modèles.
- `PCA.ipynb` : Analyse en composantes principales (Principal Component Analysis).
- `Regression.ipynb` : Analyse de régression et modélisation prédictive.
- `Supraconductivité/TP9 Supraconductivté.ipynb` : Notebook dédié à l'étude des données de supraconductivité.

## Jeux de données

- `Jeu_de_Données/labels.csv` : Fichier d'étiquettes pour les données d'image.
- `Jeu_de_Données/pixels.csv` : Fichier de pixels pour les images associées.
- `Supraconductivité/superconductivity_data.csv` : Jeu de données utilisé pour l'analyse de supraconductivité.

## Objectif

Le dépôt vise à explorer des techniques de machine learning classiques et des méthodes d'analyse de données, en utilisant des exemples concrets de classification, régression, réduction de dimension et validation.

## Utilisation

1. Ouvrir les notebooks `.ipynb` avec Jupyter Notebook, JupyterLab ou VS Code.
2. Exécuter les cellules dans l'ordre pour reproduire les analyses.
3. Vérifier que les jeux de données sont présents dans les dossiers `Jeu_de_Données` et `Supraconductivité`.

## Remarques

- Les noms de fichiers et dossiers contiennent des accents et des espaces ; certains outils peuvent nécessiter un encodage ou un chemin adapté.
